# Идеи и планы

Черновой список, чтобы обсудить с ребятами. Порядок примерный: сверху то, что даёт больше пользы за меньшие силы.

## Название

Проект скоро будет не только про фильмы, поэтому лучше слово без «кино»:

| Название | Почему |
|---|---|
| **Жребий** | Коротко и точно: случайный выбор. Подходит и к фильмам, и к играм. |
| **Вертушка** | Про колесо, звучит по-домашнему, легко запомнить. |
| **Барабан** | Отсылка к «Полю чудес», сразу понятно, что крутим. |
| **Крутилка** | Разговорное, весёлое. |
| **Чё смотрим** | Фраза, которую все и так пишут в чат. Для игр хуже. |

## 1. Оценки после просмотра

Самое ценное из того, что обсуждали, потому что из оценок дальше растёт всё остальное.

- После победы у фильма появляется статус «смотрим». На следующий день (или по кнопке «Посмотрели») каждый ставит оценку от 1 до 10 и пишет пару слов.
- Раздел «Посмотрели» в комнате: постер, средняя оценка, оценки каждого, комментарии.
- Итог оценок уходит в Discord через вебхук.
- Статистика компании: у кого лучший вкус (средняя оценка фильмов, которые человек добавил), самый спорный фильм (наибольший разброс оценок), сколько фильмов посмотрели за месяц.

Для этого нужен вход через Discord, иначе оценки не привязать к человеку. Он уже сделан.

## 2. Умное колесо (система релевантности)

Шанс фильма сейчас задаётся вручную. Его можно считать из данных:

- **Голоса «хочу»**: каждый отмечает фильмы, которые хочет. Больше голосов, больше сектор.
- **Ожидание**: фильм, который давно в списке и не выпадал, понемногу растёт.
- **Разнообразие**: жанр, который смотрели в прошлый раз, получает меньше шансов.
- **Вкусы**: из прошлых оценок понятно, кто что любит. Фильм, который понравится большинству из присутствующих, получает бонус.
- **Вето**: у каждого одно вето на вечер, чтобы убрать фильм до прокрута.

Важно показывать, почему у фильма такой шанс, иначе колесо будет казаться нечестным.

## 3. Рулетка по играм

- У комнаты появляется тип: фильмы или игры.
- Поиск игр с обложками через RAWG API (бесплатный ключ) или IGDB.
- Фильтры: число игроков (кооператив на 2, 4 и т. д.), бесплатные или платные, платформа.
- **Что есть у всех**: через Steam Web API можно найти игры, которые есть в библиотеке у каждого (если профили открыты), и крутить только их.
- Оценки после игрового вечера работают так же, как для фильмов.

## 4. Группы

- Постоянная компания вместо разовых комнат: участники, общий список «хотим посмотреть», история и статистика за всё время.
- Комнаты становятся вечерами внутри группы.
- Доступ только участникам группы, приглашение по ссылке.

## 5. Discord

- **Бот** со слеш-командами: `/крутить` запускает колесо в комнате, `/добавить Интерстеллар` добавляет фильм, результат приходит в канал.
- Событие Discord «Киновечер в пятницу 21:00» прямо из комнаты.
- Activity в голосовом канале (колесо внутри Discord) возможно, но это заметно сложнее.

## 6. Мелочи, которые сделают приятнее

- Трейлер в карточке фильма (TMDB отдаёт ссылки на YouTube).
- Где посмотреть: стриминги из TMDB (watch providers).
- Длительность фильма и предупреждение «больше трёх часов».
- Реакции во время прокрута (эмодзи летят над колесом у всех).
- Сектор-сюрприз: выпал, значит выбирает тот, кто нажимал.
- Тёмный экран «смотрим» с таймером и кнопкой «посмотрели».

## Техническое

- Когда появятся оценки и группы, JSON-файл стоит заменить на SQLite. Встроенный в Node модуль `node:sqlite` позволит обойтись без зависимостей.
- Резервная копия папки `data` раз в сутки.
