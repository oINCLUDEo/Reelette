# Reelette

Колесо для выбора фильма на киновечер. Создаёте комнату, кидаете ссылку друзьям в Discord, каждый добавляет фильмы. Колесо крутится у всех одновременно, результат выбирает сервер.

## Что умеет

- **Экран комнаты «Сеанс»** (концепт со всеми состояниями — `brand/room-concepts.html`). Сетка 12 колонок: поля и интервалы 24, модуль 8; страница на компьютере не прокручивается. Фон — размытый постер фильма под стрелкой (два слоя сменяются плавно, на быстром прокруте фон не дёргается), поверх световое кольцо колеса. Слева стеклянная панель фильмов (колонки 1–3): логотип и название комнаты (по клику настройки), оценка последнего фильма, вкладки «Фильмы» и «Выпадало», поле быстрого добавления, строка «Ваши голоса», список, внизу «сейчас играет». Сцена (колонки 4–12) — подсетка с теми же линиями: сверху режим и вплотную к нему «До победителя» (выезжает, когда выбрано выбывание), справа аватарки и капсула «Развлечения / Пригласить / Настройки»; слева «под стрелкой» — один текстовый столбец без значков: название, под ним год, длительность, жанры и «Добавил(а)» одним стилем, а когда выбывание идёт — «Осталось N из M» с полоской пути к финалу. Столбец стоит на вертикали подписи «Обычный» в переключателе режимов и держится на оси центра колеса: название растёт вверх (до трёх строк), прогресс вниз, при смене названия ничего не прыгает; справа колесо (колонки 7–12), под ним статус с кнопками и капсула реакций с полем «Написать всем». Колесо подстраивается под свободное место, но не больше 960px; раскладка не шире 2200px. На 1024–1279px панель на 4 колонки, «под стрелкой» — строкой над колесом. До 1023px всё в одну колонку, фильмы выезжают шторкой снизу (в свёрнутом виде видны заголовок и музыка).
- **Оформление** в духе Apple: стекло только над цветным фоном (панель фильмов, капсулы управления, реакции), скругления концентричные (панель 28 → элементы 20 → кнопки 18–22), у кнопок с текстом высота от 40 и поля по 20px. Вторичный текст в комнате — прозрачный белый (78% и 55%), а не серый из темы: на цветном фоне он не тонет. Кнопка «Крутить» в центре колеса — главное действие, под ней «N на колесе», если часть фильмов выбыла, уже выпадала или скрыта фильтрами. На секторах с постером название пишется только целиком (длинное можно ужать до 75%), иначе остаётся один постер; у сектора без постера длинное название по-прежнему обрезается многоточием. Свет вокруг колеса — в тон постера под стрелкой. Оценка в панели — две строки по пять кнопок высотой 36. Вес фильма у создателя появляется при наведении на строку (на сенсорных экранах виден всегда).
- **Победитель** открывается на весь экран, как страница фильма: размытый постер фоном, текст слева, постер справа, «Смотреть» первой кнопкой. Выбывший в топ-5 показывается небольшой карточкой.
- **Движение** (при «уменьшить движение» в системе почти всё отключено):
  - название под стрелкой меняется барабаном, когда колесо медленное: старое уходит вверх, новое поднимается снизу; зачёркнутое выбывшее падает вниз. Число в «Осталось N из M» катится вниз, как счётчик;
  - выбывание: колесо глухо проседает, карточка выбывшего постера вылетает из-под стрелки по физике броска (подлёт, падение с ускорением, снос гаснет), кувыркается в 3D, показывает тёмный оборот и падает за край экрана (когда окно выбывшего не показывается: на разгоне и в финале);
  - главы: на первом прокруте топ-10, топ-5 и полуфинала через колесо проходит название этапа, а виньетка и приглушение панели с каждым этапом сильнее (на компьютере наведённая панель возвращается);
  - финал: постеры финалистов поднимаются со своих секторов колеса, отсчёт бьётся толчками, после «1» фон заставки гаснет, а постеры возвращаются в колесо;
  - победитель: постер прилетает из сектора под стрелкой на своё место, фон вспыхивает, текст проявляется по строке. В финале выбывания окна выбывшего нет, чтобы победитель вылетал из открытого колеса; у дуэли полёта нет;
  - с музыкой прокрута лампы на ободе вспыхивают на каждой сильной доле.
- **Развлечения** — меню в шапке: «Угадай мелодию», караоке и броски.
- Комнаты по ссылке. Вход через Discord (аватар и имя из Discord) или как гость. Видно, кто сейчас в комнате. Комнату можно удалить в настройках; если её создали через Discord, удалить может только создатель.
- Поиск фильмов с постером, описанием, годом и рейтингом (Кинопоиск или TMDB). Без ключа фильмы добавляются вручную, по названию.
- Если на сервере заданы оба ключа, источник переключается в настройках комнаты: «Поиск фильмов» → Кинопоиск или TMDB. Настройка общая для комнаты, уже добавленные фильмы не меняются.
- Постеры идут через свой домен (`/img`): у части людей в России `image.tmdb.org` не открывается, а сервер до него достаёт. Заодно чужие сервисы не видят гостей комнаты.
- Добавление списком: по одному названию на строку, постеры подтягиваются сами.
- Список фильмов сгруппирован по тем, кто их добавил: у группы видно, сколько фильмов человека ещё на колесе (на выбывании число тает с каждым прокрутом), и долю на колесе; в группе сначала участвующие фильмы, потом выбывшие и уже выпавшие. По клику открывается профиль.
- Удалять чужие фильмы, очищать историю и список может только создатель комнаты; свои фильмы удаляет каждый сам.
- Вес фильма (кнопки − и +) меняет только создатель комнаты. Если добавить фильм, который уже есть, ему уходит голос добавившего (если голоса остались). В старых комнатах без создателя его можно назначить в настройках: «Стать создателем комнаты».
- **Замок прокрутов**: создатель комнаты может включить «Крутит только создатель». Пока замок включён, прокрут, серию, дуэль, отмену отсчёта и остановку серии запускает только он; остальные голосуют и добавляют фильмы как обычно.
- **Закрыть добавление фильмов**: переключатель создателя. Во время выбывания добавлять фильмы нельзя никому, чтобы колесо не менялось посреди серии.
- **Показывать выбывших**: личная настройка. Выбывший фильм всегда зачёркивается над колесом, а окно с ним появляется, когда на колесе осталось пять фильмов и меньше; если выключить, окна не будет совсем.
- **Наши треки**: вверху панели музыки (открывается по карточке «Музыка» внизу списка фильмов) две плитки, «Ворона» и «andy warhol» (Kai Angel). Одно нажатие включает трек у всех, играющий подсвечен. На «Вороне» по сцене ещё и пролетает ворона с «КАР!», так же как от реакции-вороны.
- **Голоса**: у каждого 3 голоса, на фильм не больше одного своего. Оценка своего последнего выпавшего фильма меняет число голосов: средняя 8–9,9 даёт +2, 10 — +4, ниже 6 оставляет 1 голос вместо 3. Держатся вместе с бонусом к шансам, пока снова не выпадет фильм этого человека. Голос добавляет фильму около 4% колеса (фиксированные 4 пункта к основе в 100), засчитывается до 4 голосов на фильм. Прибавка одинаковая, сколько бы фильмов ни было у автора. Голоса за выбранный фильм возвращаются.
- **Равные шансы** (включено по умолчанию): колесо сначала делится поровну между участниками, потом доля каждого делится между его фильмами. 60 фильмов одного весят столько же, сколько 2 у другого.
- **Оценка после просмотра**: остальные оценивают выбранный фильм от 1 до 10, автор свой фильм не оценивает. Любой фильм из истории можно оценить позже (в истории у него метка «Оценить»). Свою оценку можно поменять в течение минуты, потом она закрывается. Средняя оценка даёт фильмам автора множитель: ниже 6 — ×0,5, 6–7,9 — без изменений, 8–9,9 — ×1,5, 10 — ×2. Множитель держится, пока снова не выпадет фильм этого автора: тогда он сгорает, и новый фильм оценивают заново. Бонусы и штрафы у разных людей действуют одновременно. Действующий множитель виден значком «×1,5» у процента человека в списке фильмов, подробности — в подсказке.
- **Мини-профили**: по клику на аватар или имя видно, сколько фильмов человек добавил, сколько раз выбирали его фильмы, за что он голосует и любимые жанры.
- Режимы:
  - **Обычный**: один прокрут выбирает один фильм.
  - **На выбывание**: каждый прокрут выбивает один фильм, побеждает последний. Победитель серии выбирается по тем же шансам, что в обычном режиме, и в списке слева проценты — это шанс выиграть. Колесо показывает шанс вылететь: он считается для каждого фильма на всём колесе и обратен его шансу выиграть, так что у фаворитов (голоса, вес, бонус за оценку) узкие секторы. Выбывший сектор вспыхивает и схлопывается, его название зачёркивается над колесом, «Осталось N из M» с полоской прогресса стоит слева под фильмом (на узких экранах — строкой под колесом). Серия прокрутов без остановок («До победителя», рядом с режимом) включена по умолчанию.
  - **Темп выбывания** подбирает сервер (`elimPace` в `server.js`) по числу фильмов на колесе: от 21 — прокрут 2,8 с и пауза 1,1 с, 11–20 — 4 с, 6–10 — 6,5 с, 4–5 — 10 с, полуфинал (3) — 14 с, финал — 20 с. Ползунок длительности действует только в обычном режиме.
  - **Финал**: перед ним заставка с двумя финалистами и отсчётом 4 с, колесо делает замах назад и долго доползает, стрелка встаёт у самой границы сектора (исход от этого не меняется, он выбран заранее). Остальная страница затемняется, лампочки на ободе горят все и дышат, на доползании бьётся сердце. В полуфинале замах поменьше и колонка фильмов приглушается.
- Отсчёт перед прокрутом (3, 5 или 10 секунд) со звуком, его можно отменить. Серию на выбывание можно остановить: текущий прокрут доиграет, следующий не начнётся.
- **Дуэль**: третий режим. Фильмы выходят парами, все в комнате голосуют, проигравший вылетает. Когда проголосовали все, итог подводится сам; при ничьей решает жребий с учётом веса.
- **Фильтры** перед прокрутом: длина, год, жанры. Общие для комнаты, работают во всех режимах.
- Длительность, жанры и трейлер подтягиваются из TMDB или Кинопоиска в фоне после добавления фильма. Трейлер открывается прямо в карточке.
- Кнопка Кинопоиска в карточке фильма и в окне победителя: ведёт на страницу фильма, если он найден на Кинопоиске, иначе на поиск.
- **Смотреть в Kodik**: в окне победителя и в карточке фильма есть кнопка «Смотреть» — плеер Kodik открывается окном поверх сайта, озвучку, качество и серию переключает сам плеер. Кнопка «Включить всем» открывает тот же фильм у всех в комнате. Плеер ищет фильм по номерам IMDb и Кинопоиска, они подтягиваются вместе с деталями. **Без своего токена Kodik отдаёт только аниме** (и только по номеру IMDb), обычные фильмы не находятся — для них нужен доступ к базе, см. ниже.
- Под музыку прокрута кольцо вокруг колеса пульсирует от баса, на сильных долях расходятся волны.
- История выпавших фильмов. Выпавшие фильмы на колесо больше не попадают, в списке они помечены «уже смотрели». Создатель комнаты может убрать фильм из выпавших в его карточке: фильм вернётся на колесо, его оценки удалятся.
- Вебхук Discord: победитель приходит в канал карточкой с постером. Бот не нужен, вебхук создаётся в настройках канала: Интеграция → Вебхуки.
- Звук: мягкие щелчки колеса и сигналы отсчёта, музыка при прокруте (генерируется в браузере, темп следует за скоростью колеса, в серии не прерывается между прокрутами, на победу короткая фанфара).
- **Общая музыка из YouTube** внизу панели фильмов («сейчас играет»): у всех в комнате играет один трек с одной позиции, есть общая очередь (добавить, поднять, убрать, пропустить). Когда трек кончается, сервер включает следующий из очереди, а если очередь пуста, музыка останавливается. Недоступные для встраивания видео пропускаются. Громкость у каждого своя. Внизу панели фильмов строка с обложкой, паузой, следующим треком и очередью; по клику на обложку рядом открывается панель с очередью, громкостью и кнопками «С начала» и «Выключить у всех». Видео не показывается: плеер YouTube нужен только ради звука и стоит невидимым. Джемы YouTube Music подключить нельзя: у них нет публичного API.
- **Караоке**: кнопка в шапке включает сцену для всей комнаты. Вместо колеса большой плеер YouTube (у всех одно видео с одного места), прогресс песни, очередь с певцами, оценки выступлений от 1 до 10 (себя оценить нельзя) и «Звёзды вечера». Текст песни подтягивается из открытой базы LRCLIB и идёт по таймингам: текущая строка крупно и заливается цветом. Есть сдвиг текста ±0,5 с и ручной поиск, если подобрался не тот.
- **Угадай мелодию**: кнопка в шапке. Треки берутся из всего, что играло в комнате (общая музыка и караоке), и из очереди. Каждый раунд играет фрагмент из середины трека, видео закрыто заглушкой. Ответ сравнивается мягко: регистр, «ё», опечатки и транслит не мешают, исполнитель тоже засчитывается. Первый угадавший получает 3 очка, второй 2, остальные 1. Подсказка с первыми буквами появляется на последней трети раунда. Победитель получает бейдж «Знаток».
- **Сообщения**: поле «Написать всем» под колесом, сообщение пролетает по сцене справа налево с ником в оформлении автора. Ленты на сайте нет — общаются в Discord. Пролёт можно выключить у себя: настройки → «Сообщения поверх колеса». Неверные версии в «Угадай мелодию» тоже пролетают, правильные ответы скрыты.
- **Броски**: помидор, яйцо, торт и роза в панели реакций. Выбираешь предмет, кликаешь по сцене, и у всех он прилетает по дуге в ту же точку и шлёпается (брызги стекают и исчезают, роза рассыпается лепестками). В караоке попадание в видео засчитывается певцу текущего выступления.
- **Реакции**: панель под сценой, эмодзи с ником всплывают у всех над колесом или караоке. Лимит 10 реакций за 2,5 секунды на человека.
- **Наши хиты**: каждый трек, который играл в комнате, сохраняется (сколько раз, кто пел, лучший балл). В караоке вкладка с поиском, трек ставится в очередь в один клик.
- **Оформление профиля** (общее для всех комнат, `data/profiles.json`) — в своём профиле кнопка «Изменить оформление» открывает редактор с живым превью и вкладками «Ник», «Аватар», «Профиль»; несохранённые изменения не теряются молча: цвет ника (однотонный или градиент), шрифт, эффект (свечение, перелив, пульс, глитч, волна, неон, радуга), значок и один из своих бейджей рядом с ником, рамка аватара (в том числе огонь, лёд, токсик, голограмма), фон профиля, статус.
- **Бейджи** зарабатываются сами: Кинокритик, Хитмейкер, Тонкий вкус, Коллекционер, Меломан, Звезда сцены, Знаток, Душа компании. Неполученные видны с полоской прогресса, по наведению — как получить.
- Три палитры (настройки → «Палитра»). Крутить можно кнопкой в центре колеса или пробелом.

## Запуск на сервере

```bash
git clone <репозиторий> reelette && cd reelette
cp .env.example .env      # впишите ключ Кинопоиска или TMDB
docker compose up -d --build
```

Вместе с сайтом поднимается Caddy: он получает сертификат Let's Encrypt для домена из `DOMAIN` и отдаёт сайт по HTTPS. Нужны свободные порты 80 и 443 и A-запись домена на IP сервера. Данные лежат в `./data/rooms.json`.

### Ключ для поиска фильмов

- **Кинопоиск**: бесплатный ключ на https://kinopoiskapiunofficial.tech (после регистрации, лимит запросов в сутки). Названия и описания на русском.
- **TMDB**: ключ на https://www.themoviedb.org/settings/api. Подходит и API Key (v3), и Read Access Token. Из России TMDB может быть недоступен, на зарубежном сервере работает.

Можно задать оба ключа: тогда в настройках комнаты появится переключатель источника, а `MOVIE_PROVIDER` задаёт только значение по умолчанию. Картинки обоих сервисов сайт отдаёт со своего адреса, так что блокировки у гостей на них не влияют.

### Kodik — доступ к базе

Кнопка «Смотреть» работает сразу, но из коробки Kodik отдаёт только **аниме**: публичный доступ ищет по номерам IMDb и Shikimori, обычные фильмы и сериалы в нём не находятся («Плеер не найден»). Так устроен сам Kodik, настройками сайта это не лечится.

Чтобы находились обычные фильмы, нужен свой токен и доступ к базе — их выдаёт Kodik по письму на support@kodikres.com (адрес указан в их же плеере). В письме обычно спрашивают адрес сайта, о чём он и какая посещаемость. Полученный токен кладётся в `.env`:

```
KODIK_TOKEN=ваш_токен
```

С токеном сайт ещё и заранее знает, есть ли фильм в базе, какие есть озвучки с качеством и сколько в сериале сезонов — это делает `kodikwrapper`. Если основной адрес API с сервера не открывается, можно указать запасной: `KODIK_API_URL=https://kodikapi.com`.

### Вход через Discord

1. https://discord.com/developers/applications → New Application.
2. OAuth2 → Redirects → добавьте `https://reelette.ulya.space/auth/discord/callback`.
3. Скопируйте Client ID и Client Secret в `.env`: `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, а также `PUBLIC_URL=https://reelette.ulya.space`.
4. `docker compose up -d`.

Работает только по HTTPS через домен: cookie входа помечена как Secure. Без ключей кнопки Discord не показываются, остаётся гостевой вход.

### За reverse proxy

Обновления идут через Server-Sent Events, поэтому для `/api/rooms/*/events` у прокси нужно выключить буферизацию. Пример для nginx:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Connection '';
    proxy_buffering off;
    proxy_read_timeout 1h;
}
```

Caddy работает без дополнительных настроек: `kino.example.com { reverse_proxy 127.0.0.1:3000 }`.

## Устройство

- `auth.js`: вход через Discord (OAuth2) и сессии в cookie.
- `server.js`: Node.js без зависимостей. Статика, JSON API, SSE, хранение в JSON-файле, запросы к Кинопоиску и TMDB, вебхук Discord.
- `public/`: фронтенд на чистом JS. `wheel.js` рисует колесо (canvas), `backdrop.js` рисует световое кольцо вокруг колеса, `audio.js` отвечает за звук и музыку (Web Audio), `fx.js` ловит бас и доли музыки прокрута для эффектов, `app.js` отвечает за интерфейс.

Результат прокрута выбирает сервер (`crypto.randomInt`) и рассылает всем клиентам угол остановки, так что у всех колесо останавливается одинаково.

Локальный запуск без Docker: `node server.js`.
